# Big Data Project: Rigorous Explanation of Methodology and Execution

Based on a thorough analysis of the provided Jupyter Notebook (`big-data-project-final.ipynb`), this document provides a rigorous, step-by-step technical explanation of the pipeline built in this project. The project is fundamentally divided into two major phases: (1) **Network Graph Processing & Feature Engineering**, and (2) **Dimensionality Reduction & Predictive Modeling**.

## Phase 1: Network Graph Processing & Feature Engineering

The initial phase focused on parsing an immensely scaled directed graph dataset (user-follower relations, e.g., Twitch or similar social networks) to extract structural network features.

1. **Data Ingestion & Cohort Selection**
   - The graph dataset consists of directed edges marked as `Follower` and `Target` pairs.
   - The dataset was analyzed for general network statistics (total unique nodes, in-degree/out-degree counts). 
   - A distinct cohort of **1,000 specific anchor nodes** was sampled. This was constructed by aggregating the top 500 nodes with the highest out-degree (who follow the most people) and the lowest 500 nodes with the minimum out-degree (who follow the fewest). 

2. **Breadth-First Search (BFS) & Neighborhood Extraction**
   - For every chosen anchor node in the 1000-node cohort, the script computes a local ego-network up to a depth of 4 (the "4-neighborhood" graph). 
   - Restricting search depth explicitly to `d <= 4` via customized Breadth-First Search (BFS) logic is a computational necessity, as unfiltered traversals were documented visiting millions of subsequent nodes & edges.

3. **Feature Vector Extraction & Dense Subgraph Detection**
   - **Vector Creation:** Over the extracted BFS 4-neighborhood graphs, the algorithm isolates the "top 500 highest-degree nodes" natively within that specific local radius. The out-degree frequencies of these 500 local influencers serve as continuous numerical features, generating a fixed 500-unit continuous representation for each original anchor node.
   - **Iterative K-Core Pruning & Clique Analysis:** The 4-neighborhood graph inherently contains considerable noise. To detect extremely dense communities, it applies an iterative degree-filtering process. Running for 20 loop cycles, it dynamically prunes nodes with a cumulative degree less than 10.
   - **Dependent Variable Generation:** On the filtered network, NetworkX is utilized to find the size of the Maximum Clique. If the `max_clique_size >= 11`, a binary target indicator variable (`clique_exists` or `k11`) is flagged as 1, otherwise 0.
   - The 501 variables (500 features + 1 target) are concatenated and serialized into rows of CSV files.

## Phase 2: Dimensionality Reduction & Predictive Modeling

The second phase involved ingesting the feature matrix compiled previously (loaded via `BDA1000pts.csv`), addressing the curse of dimensionality over the 500 graph-topological metrics, and implementing supervised machine learning classification.

1. **Pre-Processing & Scaling**
   - Redundant identifier nodes were scrubbed. The remaining columns were split into independent continuous features ($X$) and the dependent binary label ($y$).
   - A standard 80/20 train-test split pattern was applied. 
   - Z-score normalization (`StandardScaler`) was systematically applied before undergoing multivariate component analysis so that magnitudes wouldn't arbitrarily influence variance covariance logic.

2. **Principal Component Analysis (PCA)**
   - **Eigen Decomposition:** Computes the dataset's covariance matrix, deriving eigenvalues and eigenvectors.
   - **Variance Diagnostics:** Assessed the importance of Principal Components using individual Explained Variance plots, Cumulative Explained Variance, and Scree Plots. The empirical testing discovered:
     - ~80% of data variance is effectively captured within merely the **top 7 principal components**.
     - Nearly ~99% variance spans more distributed components.
   - The projection space distributions were meticulously plotted via highly interactive 2D and 3D plotting solutions (using matplotlib and plotly), illustrating distinct sub-clusters among binary target classes iteratively across 2, 3, 5, and 7 compressed dimensions.

3. **Binary Classification System (Logistic Regression)**
   - The dimensionality reduction acted as a direct pipeline input to a Logistic Regression threshold classifier.
   - The classifier was repeatedly trained and scored iterating over differing magnitudes of retained components ($N = 263, 50, 30, 20, 7$).
   - **Performance Results:** The quantitative evaluation (using Test Accuracy and Confusion Matrices) demonstrated that model stability and predictive efficacy peaked when trained precisely on `$N=30$` reduced components.
   - Regardless of the $N=30$ accuracy peak, secondary Logistic models were fit using the 7 most impactful components to visualize deterministic 2D/3D decision boundaries visually separating the distinct regions of predictions mapped against target classes.

## Conclusion

This project seamlessly combines complex big-data graph theory with downstream predictive analytics. It proves that by extracting limited-radius topological traits (influencer degrees) and target graph metrics (dense $k=11$ cliques), high-dimension local phenomena can be reduced efficiently (via PCA) to power linear, interpretable classifiers (Logistic Regression) with highly successful segregations.
